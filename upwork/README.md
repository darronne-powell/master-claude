# Upwork system for Claude

One folder that teaches your Claude to run your Upwork work the way a working freelancer runs theirs:

- **Proposals.** Paste a job link and get a researched letter, screening answers, a price and a boost, submitted on your "send". If you want, a routine can scout fresh jobs and draft for you.
- **Buyer replies.** Paste a buyer's message and get a full reply that answers, prices and moves toward the contract.
- **Client work.** Sign in to the client's WordPress, Shopify, Squarespace, Wix or Webflow, say "take over", and Claude does the job in that tab.
- **Delivery.** When a milestone is done you get the delivery messages and a report for the client.
- **Profile and numbers.** Claude keeps your Upwork profile current and counts your week: proposals, Connects, replies, hires.

## Install

1. In the Claude desktop app, open Settings, Connectors, and connect **Upwork** with your freelancer account.
2. In Chrome, on the profile where your Upwork is signed in, add the Claude extension and sign in with the same Claude account.
3. Unzip this folder somewhere you'll keep it (for example Documents/upwork-claude-system).
4. In the Claude app, open the Code tab and start a session in that folder.
5. Paste this:

```
Read START-HERE.md and set this up for me. Ask me the setup questions one at a time.
```

Claude asks you 15 questions about your niche, proof, rates and how hands-off you want it, then tests one real job with you.

After that, read `HOW-IT-WORKS.md`. It explains each part and what to say to use it.
