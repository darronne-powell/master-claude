# Start here / Commencez ici

Four steps. Nothing else to read.

1. Put this folder somewhere sensible (your Documents folder is fine). Name it whatever you like.
2. Open the **Claude Desktop app**, click the **Code** tab, and open this folder. On Windows, install [Git for Windows](https://git-scm.com/download/win) and restart Claude if the Code tab asks for it.
3. Leave Claude's permission mode on **Auto** or **Ask permissions**. Approve actions as Claude explains them. Do not turn on Bypass permissions on a normal computer.
4. Type `/install` and press enter.

Claude takes it from there, in French or English, your choice. The whole setup is a conversation: it asks, you answer, it builds. Set aside about three hours end to end. The longest part is the interview about your practice and your clients, and that's the one worth not rushing, because everything else is downstream of it.

You need a paid Claude plan with access to Code. You do **not** need a GitHub account before you begin. You can stop at any point and pick up where you left off by typing `/install` again.

## Once you're set up

1. **`/prime`** at the start of every session. It loads your practice and your client board back into Claude's head.
2. **Ask when you're stuck.** Plain language, any language. Claude knows what's in this workspace and will pick the right tool.
3. **`/proposal`** for every job you go after. **`/new-client`** the moment a lead shows up.
4. **`/weekly-review`** on Friday. **`/handoff`** when a session gets long. **`/log`** at the end, though it mostly runs itself.

The longer version is `reference/how-to-use-this.md`. You can also just ask for it.
